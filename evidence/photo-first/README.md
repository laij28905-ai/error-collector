# 图片优先收口 · 2026-10-30

## 实际改动

1. 录入页选图后只突出“框选题目”“保存这张图”。“题号或备注”选填，不填也能存；图片是原题依据，OCR、Key 和知识点均不是保存前提。
2. 保存成功直接显示刚保存的题图，提供继续从同页选题、查看错题本、补充文字或解析。整页保留在内存用于连续框选，刷新不会保留未保存整页；已保存的选区在数据库中。
3. 错题卡片使用原图缩略图，标题使用备注或“学科 · 题目编号”；不再用“未分类”占据标题。筛选/批量管理默认收起，空列表区分没有记录和筛选无结果，均有下一步按钮。
4. 复习空页面区分从未录题和今天无到期任务。个人页直接显示完整备份入口。
5. OCR 与 AI 移至已保存题目的详情。提取文字先给候选，确认才更新原记录；不新增重复题，不移除原图。AI 未配置时引导设置，规则复盘明确标注来源。
6. Service Worker 先安装应用页面，不再等 61 MB OCR 下载。OCR 仅在用户主动点击后下载，使用原独立缓存、大小/SHA 校验与已下载文件复用。显示已校验 MB 与进度，不伪造实时速度或预计完成时间。现有用户数据与 OCR 缓存不清理。

## 用户手机验收步骤

1. 打开原网站，保存当前编辑内容后接受更新。首次使用联网等到“图片记录已就绪”；不用下载识别包、不用填 Key。
2. 选择一张试卷，框选第 3 题，完成后点“保存这张图”；备注留空或填“第 3 题”，点“保存错题”。
3. 核对保存成功显示的题图，点“继续选下一题”记录下一题；同页连续选题也可在保存弹窗点“保存并选下一题”。
4. 进入错题本检查三条缩略图，关闭再打开应用，检查图片还在；进入复习查看原图。
5. 断开 Wi-Fi 和移动数据，再打开已准备的应用，重复选图、保存、查看、复习。新地址/新浏览器需要先联网准备，不能把缓存视为跨设备共享。
6. 需要文字时再下载识别包，或在“我的”配置自己的视觉模型；打开已保存题目 → “提取图片文字（选用）”。原图始终保留。
7. 在“我的”点击“备份全部错题”，换设备前保存导出的文件。

## 未验证与限制

- 真实手机摄像头权限、系统输入法和浏览器内嵌页行为仍由用户真机验收，桌面触摸模拟不能替代。
- AI 仍需用户自行配置支持识图且允许浏览器请求的服务，未使用用户 Key 做真实厂商验证。
- 手写数学、表格和复杂公式的离线准确转写未解决；照片保存不依赖这些能力。
- 首次页面访问必须联网，之后离线可用的前提是应用页面安装完成；浏览器数据被清除或系统回收后需要重新准备，并依靠用户备份恢复记录。
- 本轮未引入自动找边、四角校正、自动分类或新复习算法。
