# 错题助手

一个轻量化的高中错题整理网页应用，主要用于拍照或上传题目图片、OCR 识别文字、按学科和知识点归类，并在本地进行复习管理。

## 功能

- 拍照或上传图片录入错题
- 使用 Tesseract.js 进行中文和英文 OCR 识别
- 自动根据关键词推测学科
- 按学科、知识点保存错题
- 本地错题本浏览和筛选
- 复习模式，可标记已掌握或需复习
- 导出本地错题数据为 JSON

## 使用方式

直接打开 `app.html` 即可使用。首次进行 OCR 识别时，浏览器需要从 CDN 下载识别引擎和语言包，请保持网络可用。

如果需要使用相机功能，建议通过 HTTPS 页面访问，或在支持本地权限的浏览器环境中打开。

## 数据说明

应用数据保存在浏览器本地 IndexedDB 中，不会自动同步到服务器。清除浏览器数据、更换浏览器或更换设备后，本地错题数据可能不可用。重要数据请使用导出功能备份。

## 注意事项

- OCR 依赖外部 CDN，网络不稳定时可能加载失败。
- 当前项目是单文件前端应用，适合个人使用或原型演示。
- 后续如果功能继续增加，建议拆分为独立的 CSS、JavaScript 和资源文件。
