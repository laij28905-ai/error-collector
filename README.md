# 错题复盘助手

面向高中学生的离线错题采集与 AI 个性化复盘系统。

## 项目定位

本项目不是传统“拍照搜题”工具。它更关注错题的长期沉淀和复盘训练：学生在没有网络时也能记录错题，有网络时再使用 AI 进行错因分析、生成解析和举一反三练习。

## 目标用户

- 高中学生
- 需要整理纸质试卷、作业、练习册错题的学生
- 网络环境不稳定但仍希望持续记录学习问题的学生
- 希望通过错题复盘提升薄弱知识点的学生

## 核心功能

### 1. 离线错题记录

- 支持拍照或上传错题图片
- 无网络时仍可保存错题图片和题目文字
- 支持手动校正 OCR 识别内容
- 使用浏览器本地存储保存错题
- 自动记录学科、知识点/错因和创建时间

### 2. 联网 AI 复盘

- 对错题进行错因分析
- 提供分步骤解题建议
- 生成类似题，帮助举一反三
- 给出复习安排建议
- 为后续接入真实 AI 接口预留产品入口

## 创新点

- **离线优先**：先保证任何场景都能记录错题，不让错题丢失。
- **复盘导向**：重点不是直接给答案，而是分析错因和训练迁移能力。
- **举一反三**：通过类似题巩固同一知识点。
- **学习资产化**：把零散错题转化为可追踪、可复习的个人学习数据。

## 使用方式

直接打开 `app.html` 即可体验。支持手机浏览器访问，也可以作为 PWA 添加到桌面。

首次在线打开后，页面会通过 `sw.js` 缓存核心文件，后续在离线状态下仍可打开页面并记录错题。

## 当前版本说明

当前版本已经实现可演示的产品闭环：

- 离线错题采集界面
- 本地错题本
- 网络状态提示
- AI 复盘页面
- 类似题生成演示逻辑
- PWA manifest
- Service Worker 离线缓存

真实 OCR 模型和真实 AI API 可在后续版本中接入。
