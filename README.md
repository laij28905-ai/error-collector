工作副本：`C:\Users\Lenovo\Documents\ChatGPT\创客竞赛\error-collector`。旧副本已改名为 `highschool-error-notebook-ARCHIVE-只读`，README 首行标记“非工作副本”，文件设置为只读；不再用于开发。

本轮收口记录与实测证据见 [evidence/closeout/README.md](evidence/closeout/README.md)。公式识别仍需要人工核对，五张真实题图的纠错耗时、真机和软键盘遮挡尚未验收。

华中科技大学创客竞赛团队 **Team Future** 的错题管理 Web 应用。面向高中学生，支持离线记录错题、联网调用 AI 生成复盘、举一反三练习与间隔复习。

## 核心能力

- **拍照 / 相册 / 粘贴录入**：调用手机摄像头、上传图片或直接粘贴剪贴板图片；拍照后可旋转、缩放、框选裁剪，再交给浏览器内 OCR 识别。
- **错题管理**：科目、知识点、错因分类，搜索与筛选，支持编辑、删除、详情查看。
- **AI 个性化复盘**：在设置中填入任意 OpenAI 兼容接口（OpenAI、DeepSeek、本地 Ollama 等），按错题生成错因分析、分步解题思路、类似题和复习建议；未配置接口时使用本地规则并标记“规则生成”。
- **间隔复习**：按 1、3、7、14、30 天安排复习，支持“再练 / 还行 / 熟练”三档反馈。
- **复习自测**：先写自己的答案或思路，再对照参考答案，并保存最近一次作答用于回顾。
- **AI 批改**：自测作答可交给 AI 对照标准答案批改，给出正确性判断和修改建议。
- **每日目标**：可设置每天复习目标，首页显示今日进度，并提醒还差几次完成。
- **学习计划**：根据待复习、薄弱知识点和每日目标生成 1/3/7 天安排及未来 7 天周计划，支持导出打印/分享。
- **深色模式**：可在应用设置中切换深色主题，夜间复习更护眼。
- **学情看板**：按学科展示掌握率，按错因展示分布，快速定位强弱项。
- **掌握趋势**：查看最近 7 天每日复习次数与新增掌握数量，支持导出。
- **题库导入**：支持导入 JSON 题库，生成“举一反三”时优先使用同主题真实题目，没有匹配时可联网请求 AI；本地规则仅给复习活动建议，不伪造类似题答案。
- **班级汇总**：教师可导入学生导出的数据，按班级查看掌握率、学生掌握情况、薄弱知识点和近 7 天趋势；点击学生可下钻查看其错题明细，并导出学生报告、班级汇总报告或学生进步榜；支持保存班级快照对比掌握率变化、导出班级报告；纯前端本地数据不能生成供别人直接查看的共享报告链接。
- **批量管理**：错题本支持多选，批量标记已掌握或批量删除。
- **批量 AI 复盘**：多选错题后一次性生成逐题错因分析、解题步骤和类似题。
- **时间筛选**：错题本可按近 7 天、本月、今年筛选错题。
- **学习反馈**：复习自动记录连续打卡天数；首页可查看每周新增、复习、掌握情况和薄弱知识点报告。
- **学习报告**：一键导出老师/家长版学习报告，包含整体统计、本周概览、最近 7 天趋势、薄弱知识点和最近错题；也可直接复制周报文本自行发送。
- **数据自主**：IndexedDB 本地存储，支持 JSON 导出、导入、完整备份/恢复和清空，数据不经过第三方服务器；超过 7 天未备份时会提醒。
- **打印复习**：一键导出 A4 版式错题打印页，包含题目、答案、AI 复盘和类似题。
- **PWA 离线**：首次联网安装时下载并校验 OCR 引擎与语言包；页面显示“离线识别已就绪”后，同一浏览器、同一地址可以离线识别、保存和复习。

## 使用方式

在仓库目录运行 `python -m http.server 8080`，打开 `http://localhost:8080/app.html`；也可以部署到 HTTPS 静态托管。不要通过双击文件的 `file://` 地址使用，Service Worker 需要 HTTPS 或 localhost。手机浏览器可“添加到主屏幕”。

首次联网安装要等“离线识别已就绪”。OCR 包共 12 个文件、61,253,597 字节，来自固定版本的公开地址，逐文件校验 SHA-256；清单在 `ocr-assets.js`。这些二进制不进入 Git，`vendor/tesseract/` 已忽略。浏览器将资源存入独立 OCR 缓存，应用升级只清理自己的旧页面缓存。换浏览器配置、地址或端口需要重新安装；从未联网安装的全新浏览器不能离线打开应用。

PWA 安装后默认打开首页；如需更快录入，可在“我的 → 应用设置”开启“打开应用直达拍照页”。长按桌面图标可快速进入错题本或复习；浏览器中也可直接访问 `app.html#capture`、`app.html#book`、`app.html#review` 跳转到对应页面。

## AI 配置

进入“我的 → AI 服务”填写：

1. 接口地址：如 `https://api.openai.com/v1` 或本地 `http://localhost:11434/v1`
2. 模型：如 `gpt-4o-mini`、`deepseek-chat`
3. API Key：OpenAI 兼容接口的密钥；本地 Ollama 可留空

保存后在错题详情页生成复盘。未配置或调用失败时使用本地规则，界面标记“规则生成”，不会把模板标成 AI 解析。规则不能替代真实解题答案。

## 云同步

在“我的 → 云同步”填写 GitHub Token 后，可以把全部错题上传到你的私人 Gist，换手机时再恢复，避免数据丢失。

1. 生成 Token 时勾选 `gist` 权限（经典 Token 页面里有单独的 `gist` 复选框，`repo` 权限不能替代）
2. 在“云同步”里粘贴 Token，点击“上传到云端”
3. 首次上传会自动创建私人 Gist，并把 Gist ID 保存在设置中
4. 新手机上填写同一个 Token 和 Gist ID，点击“从云端恢复”
5. 如需自动恢复，可开启“启动时自动从云端恢复”

Token 只保存在当前浏览器本地，请勿在公共设备上开启自动同步。

## 题库导入

在“我的 → 数据 → 导入题库”选择 JSON 文件，支持以下格式：

```json
[
  {
    "subject": "数学",
    "topic": "函数与导数",
    "question": "求函数 y=x^2-4x 的对称轴。",
    "answer": "x=2"
  }
]
```

也可以使用 `{"questions": [...]}` 包装。生成“举一反三”时会优先匹配同科目、同知识点的题目。

题库支持重复导入：相同题目会自动去重合并，方便老师导出题库、学生多次导入组成班级共享题库；也可一键导出或清空本地题库。

题库也支持云端共享：在“我的 → 云同步”填写题库 Gist ID，老师可上传题库到私人 Gist，学生填写同一个 Gist ID 一键拉取合并；公开 Gist 无需 Token 也能拉取。

老师上传题库后可直接“复制题库分享链接”，学生打开链接会自动识别 Gist ID，再点击“拉取云端题库”即可合并。

## 班级汇总

老师可导入学生导出的 JSON，单个学生文件导入时输入姓名；也可以一键导入全班文件：

```json
{
  "students": [
    {
      "name": "张三",
      "errors": []
    }
  ]
}
```

导入后在“班级汇总”查看学生掌握率与班级薄弱知识点，并导出汇总报告。

班级数据也支持云端汇总：在“我的 → 云同步”上传班级数据到 Gist，之后填写同一个 Gist ID 即可拉取合并，方便在电脑和手机间同步班级数据。

## OCR 说明

OCR 默认使用浏览器端 Tesseract.js。首次联网安装完成后，识别使用本地缓存；识别原文和校正内容并排显示。含数学符号的行进行局部 2 倍放大、二值化和孤立噪点处理；可疑符号高亮提醒“此处请对照原图”，处理建议由用户核对后一键采纳。不会把每个 `>` 强制改成 `≥`，也不会把每个 `V` 强制改成根号。

AI 视觉复核默认关闭。只有联网、手动开启并填入自己的 Key 后才显示复核入口，还需再次点击才会发送题图。默认演示流程只使用本地 OCR，不依赖 AI 视觉。

## 隐私说明

错题数据保存在当前浏览器（IndexedDB / localStorage），导出文件由用户自己保管。调用 AI 复盘会将当前题目发送到配置的接口；手动使用 AI 视觉复核还会发送当前题图。云同步仅在用户配置后使用 GitHub Gist。完整备份不导出 API Key 和同步 Token。
